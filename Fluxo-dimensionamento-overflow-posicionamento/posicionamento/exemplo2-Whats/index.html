O que são Tags Semânticas? (<article> com seu próprio <header>)

Publicado por Equipe de Desenvolvimento em 23 de Setembro de 2026.

Tags semânticas dão significado ao conteúdo web tanto para os desenvolvedores quanto para os navegadores, leitoras de tela e motores de busca (SEO). Em vez de usar divisões genéricas, cada elemento descreve seu papel no documento.

Por exemplo, a tag <mark> é usada para destacar ou grifar trechos de texto relevantes no contexto.

Tags deste artigo: HTML5, Semântica, Acessibilidade.

Elementos inline semânticos adicionais

Dentro de um texto, podemos usar elementos como:

  • <time>: Representa datas ou horários legíveis por máquina, como 14:30 ou 1º de Janeiro de 2026.
  • <code>: Representa trechos de código de computador, ex: document.querySelector('main').
  • <small>: Representa comentários secundários ou avisos legais/direitos autorais.
  • <kbd>: Representa entrada de teclado do usuário, como Ctrl + C.
  • <abbr>: Representa abreviações ou siglas, como HTML.

Mídia e Ilustrações (<figure> & <figcaption>)

A tag <figure> engloba conteúdo ilustrativo independente (como imagens, diagramas ou trechos de código) acompanhado de uma legenda com <figcaption>.

Tabela Semântica (<table>, <caption>, <thead>, <tbody>, <tfoot>)

As tabelas no HTML5 possuem tags semânticas para separar o cabeçalho, corpo e rodapé dos dados.

Tabela 1: Resumo das Principais Tags Semânticas Estruturais
Tag Tipo Descrição/Uso
<header> Bloco Cabeçalho de documento ou de uma seção.
<nav> Bloco Bloco contendo links de navegação.
<main> Bloco Conteúdo principal exclusivo do documento.
<article> Bloco Conteúdo autônomo e independente.
<aside> Bloco Conteúdo periférico ou complementar ao conteúdo principal.

Elementos Semânticos Interativos (<details>, <summary>, <dialog>)

Clique para expandir/recolher informações adicionais (<summary>)

A tag <details> permite ocultar e exibir conteúdo sob demanda sem a necessidade de scripts em JavaScript.


Esta é uma caixa de diálogo nativa (<dialog>). Ela pode ser usada para notificações, modais ou janelas de confirmação.

Barra Lateral ou Conteúdo Secundário (<aside>)

A tag <aside> representa conteúdo indiretamente relacionado ao conteúdo ao seu redor.
